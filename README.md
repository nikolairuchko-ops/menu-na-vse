# Меню на всё

Статическая редакционная лента вещей, которые складываются в готовые образы. В подборках есть товары из публичных витрин Парижа, Лондона и Дубая, цены на момент проверки и прямые ссылки на продавцов.

## Запуск

Сайт работает без сборки и зависимостей. Откройте `index.html` в браузере или запустите локальный HTTP-сервер из корня проекта:

```sh
python -m http.server 8000
```

Перейдите на <http://localhost:8000>.

## Возможности

- три кураторских образа: A.P.C. из Парижа, Burberry из Лондона и подборка Ounass UAE;
- переключение между образами, карточки с брендом, названием, оттенком и ценой;
- для A.P.C. и Burberry используются фотографии с CDN продавцов; изображения не копируются в репозиторий;
- для позиций Ounass, чьи страницы ограничивали просмотр (HTTP 429), показаны подписанные CSS-иллюстрации, а не случайные изображения;
- каждая карточка ведёт на публичную страницу товара или листинг продавца;
- адаптивная раскладка для широких и мобильных экранов.

## Источники и актуальность

Товарные позиции, названия и цены проверены по открытым страницам A.P.C., Burberry UK и Ounass UAE 14 ноября 2026 года. Фотографии загружаются напрямую с CDN продавцов и могут быть недоступны, если источник изменит адрес или ограничит запросы. Для Ounass цены сверялись по публичным листингам: некоторые страницы отдельных товаров ограничивали просмотр (HTTP 429), поэтому размер и наличие не подтверждены. Данные не синхронизируются автоматически; цены, ассортимент, размеры, наличие, доставка и налоги могут измениться. Всегда проверяйте их на сайте продавца перед покупкой.

Это только frontend-витрина: без сервера, учётных записей, AI-агента, автоматического сканирования, оформления заказа и внешних API. Чтобы обновить подборки, отредактируйте массив `looks` в `app.js`, проверив товар и цену по открытому источнику.
