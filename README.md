# Меню на всё

Адаптивный шопинг-гид по официальным онлайн-магазинам и универмагам Дубая, Парижа и Лондона. В демо-каталоге собраны 17 ссылок на площадки известных брендов и торговых домов.

## Запуск

Статический сайт без сборки и зависимостей. Откройте `index.html` в браузере или запустите локальный HTTP-сервер из корня проекта, например:

```sh
python -m http.server 8000
```

Затем перейдите на <http://localhost:8000>.

## Возможности

- поиск по бренду, магазину, городу и типу вещи;
- фильтрация по направлению (Дубай, Париж, Лондон) и категориям (одежда, сумки, обувь, аксессуары);
- ссылки ведут на официальные онлайн-магазины и каталоги продавцов;
- адаптивная раскладка и управление с клавиатуры (`/` — поиск, `Escape` — очистка запроса);
- список и описания редактируются в массиве `stores` в `app.js`.

## Актуальность каталога

Эта версия помогает быстро найти магазины, но не отслеживает цены, остатки, размеры или новые поступления и не подключена к AI-модели. Каталог ссылок поддерживается вручную. Ассортимент, наличие и условия доставки нужно проверять на сайте продавца; они могут зависеть от региона.

Для автоматического мониторинга понадобятся разрешённые источники данных (например, официальные товарные фиды или API продавцов), регулярное обновление и серверная часть. Парсинг сайтов магазинов не включён.
