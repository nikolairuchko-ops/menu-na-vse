# Меню на всё

Компактный адаптивный каталог популярных сайтов. Сервисы, магазины и службы собраны в одном месте, а быстрый поиск помогает найти нужный интерфейс.

## Запуск

Это статический сайт без сборки и зависимостей. Откройте `index.html` в браузере или запустите любой локальный HTTP-сервер из корня проекта, например:

```sh
python -m http.server 8000
```

Затем перейдите на <http://localhost:8000>.

## Возможности

- поиск по названию, описанию и ключевым словам;
- фильтрация по категориям: сервисы, магазины и службы;
- адаптивная раскладка для телефона и компьютера;
- быстрый переход к поиску клавишей `/`, очистка запроса клавишей `Escape`;
- демонстрационный каталог редактируется в массиве `sites` в `app.js`.

Все данные хранятся в клиентском коде. Серверное приложение, учетные записи и внешние API не используются.
